# IT Help Desk Ticket Management System

## Project Overview
A Java-based application designed to manage IT support tickets
and track technical issues efficiently.

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Java File Handling
- VS Code

## Features
- Create IT support tickets
- Generate unique ticket IDs
- Categorize hardware, software, and network issues
- Assign ticket priorities
- Update ticket status
- Search tickets by ID
- Save and retrieve tickets using file handling

## How to Run
1. Install Java JDK.
2. Download Main.java.
3. Open the terminal.
4. Compile: javac Main.java
5. Run: java -cp . Main
